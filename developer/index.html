用 Star ID 登录你的应用

Caelus Studio 账号体系已向第三方开放。接入后，用户可以用同一个 Star ID 登录你的网站、小程序或工具，无需额外注册。

体验完整的授权流程：登录 → 同意授权 → 获取用户信息。

打开 OAuth Demo

终端控制台

登记你的应用、管理回调地址、签发与轮换 client_secret。

进入控制台

快速开始

在前端引入 SDK，配置你的 client_id 与回调地址：

<!-- 1. 引入 SDK --> <script src="https://caelus-terminal.app.workbuddy.host/sdk/caelus-auth.js"></script> <!-- 2. 初始化并触发登录 --> <script> CaelusAuth.init({ clientId: 'your-client-id', redirectUri: 'https://your-app.example.com/callback', scope: 'star_id profile' }).requireLogin(); </script>

核心端点

授权GET /oauth/authorize
令牌POST /oauth/token
用户信息GET /oauth/userinfo
撤销POST /oauth/revoke
发现GET /oauth/metadata
