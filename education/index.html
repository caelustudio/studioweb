我们的理念

教育的大门开得更大，
潜能就走得更远。

我们相信，要创造一个更有创意的世界，教育至关重要。我们毫无保留地分享技巧与经验， 创造各种交流与学习的机会——当教育的大门能开得更大，每个人就能有更多途径发挥自身潜能。

全方位行动

从分享到开源，
行动看得见。

教育不只停留在口号上，我们把它落实在创作与社区的每一个环节。

技巧分享

教程、经验与避坑心得毫无保留地分享，从入门到进阶，每一位成员和访客都能学到真东西。

开源作品

CaelusOS 等作品在 GitHub 开放源文件，供学习、研究与二次创作，让作品本身成为教材。

社区交流

QQ 群与 B 站评论区随时开放，设计、PPT 等话题有问必答，交流中互相启发、共同进步。

经验传承

鼓励老成员带新成员，一对一行传帮带，让技巧与经验在工作室里代代相传、生生不息。

不止步

对教育的付出，
我们不止步。

教育资源长期免费开放，并随着我们的创作持续更新，永不设限。

永久免费

所有教程与资源永久免费开放，不设门槛、不看身份，学习本身就该没有价格。

持续更新

随着创作演进，教程与模板会不断迭代升级，今天的内容，明天只会更好。

人人可学

无论你是学生还是爱好者，无论起点高低，这里总有一条适合你的学习路径。

价值观

我们的价值观，
为我们导航。

环保是 Caelus Studio 价值观的重要一环，与这些信念一起，指引我们前进的方向。

设计

始于设计，忠于设计。我们用 PowerPoint 打造系统、动画与界面设计，追求极致的作品品质。

教育

我们毫无保留地分享技巧与经验，全力支持每一位成员学习、创造，开创属于自己的成功。

开源

CaelusOS 等作品在 GitHub 开放，我们相信开放的分享能让创意走得更远。

环保

一切为了地球、绿色和人类。我们以 Caelus Green 2030 碳中和蓝图为目标：先尽最大努力减排，再以自然为本的方式抵消剩余排放，力争 2030 年实现运营碳中和。
